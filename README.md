# ACS712 Current Sensor Monitoring

## Overview
A current monitoring system using the ACS712 sensor to measure electrical current with Arduino.

## Features
- Current measurement
- Real-time monitoring
- LCD display
- Accurate sensor readings

## Hardware
- Arduino Uno
- ACS712 Current Sensor
- LCD Display
- Relay

## Software
- Arduino IDE
- blynk iot
- C++
